# Masterarbeit

### About
Diese Web-Anwendung erlaubt die Simulation von Covid-19-Ausbrüchen unter Einbezug unterschiedlicher Faktoren, die sich auf Krankheitsverbreitung auswirken können. 

Dazu wird eine API des German Epidemic Microsimulation System (GEMS, https://github.com/IMMIDD/GEMS) eingesetzt, die die Simulationen serverseitig durchführt, dessen Ergebnisse dann im Frontend ausgegeben werden.

Derzeit (01.06.26) wird das Projekt unter https://gems-interface.hciuse.sh gehosted.
